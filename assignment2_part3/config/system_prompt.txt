- edit_section: replace one exact whole-line section in one workspace file. Args: {"path": "...", "old_text": "...", "new_text": "..."}.

- replace_text: replace one or all exact whole-line text matches in one workspace file. Args: {"path": "...", "old_text": "...", "new_text": "...", "all_occurrences": true_or_false}.
- run_tests: run pytest against one workspace file or directory. Args: {"path": "/workspace/shared/test_calculator.py"}. Use this to verify a test file passes after you create or edit it. pytest is preinstalled.
